# Delicii - Frontend

Acces the app at https://frontend-recipe-opal.vercel.app/home-page

FrontendRecipe is the client-side application of a full-stack recipe discovery platform designed to provide users with an intuitive, interactive, and responsive cooking experience. The application was built to help users explore recipes, discover meals based on available ingredients, and make more informed food choices through advanced filtering, nutritional search, and AI-assisted recipe classification.

From the user interface perspective, the project focuses on creating a smooth and accessible navigation flow across all major application features. Users can browse recipes, open detailed recipe pages, search by recipe type or diet, and perform advanced searches using ingredients they already have, ingredients they want to avoid, or nutritional constraints such as calories, fats, carbohydrates, proteins, cholesterol, sugar, and other dietary indicators. This functionality was designed not only to improve usability, but also to support healthier food decisions and reduce food waste by helping users cook with what they already have available.

The frontend also supports a complete user interaction layer with role-based experiences for guest users, authenticated users, premium users, and administrators. Guest users can browse recipes and view recipe details, while authenticated users gain access to more advanced functionality such as adding recipes to favorites, posting reviews and comments, and using advanced search capabilities. Premium users benefit from unlimited advanced searches, while administrators have access to moderation and approval workflows for user-submitted content. This role separation was designed to provide a personalized experience depending on the user’s level of access and platform engagement.

A key part of the frontend experience is the social and community interaction model. Authenticated users can submit reviews with ratings, leave comments on recipes, update their own reviews, and manage their favorite recipes. These interactions are displayed directly on the recipe details page, creating a more dynamic and community-driven platform where users can exchange feedback and discover recipes through other users’ experiences.

The application also includes recipe submission workflows, allowing users to contribute their own recipes by filling in forms with a title, image, ingredients, and preparation instructions. Submitted recipes are not published immediately; instead, they go through an admin validation flow, ensuring that only approved recipes become visible in the official database. This adds a moderation layer that improves content quality and reliability.

Another important feature of the frontend is the integration with the AI recipe classification service. When a user opens a recipe details page, the frontend retrieves the recipe ingredients and communicates with the AI prediction API to display an automatically generated recipe type or dietary category. This creates a smarter browsing experience by helping users quickly understand whether a recipe matches their dietary preferences or restrictions. The AI integration enhances personalization and adds a practical machine learning component directly into the user journey.

From a technical implementation perspective, the frontend uses Angular and follows a structured approach with dedicated HTTP services for different entities such as authentication, users, and recipes. It includes route management, reactive forms for input validation, authentication token handling through an interceptor, and centralized error handling for cleaner API communication. UI responsiveness and user feedback are supported through libraries such as Angular Material and ngx-toastr, while payment-related flows for premium access are integrated through Stripe.

Overall, FrontendRecipe was designed as the presentation and interaction layer of the platform, combining usability, responsive design, advanced search, role-based access, social engagement, and AI-assisted features into a complete frontend experience for a modern recipe application.
